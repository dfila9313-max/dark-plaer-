# Changelog

## Этап 1 — дизайн-система и публичный сайт (часть 1)
- Акцентный цвет: глубокий синий #234A6E.
- Компоненты: Button / ButtonLink, Field / Input, StatusDot, Badge, Card, Avatar.
- Витрина компонентов `/dev/ui` (только в режиме разработки).
- Главная страница ADMINO: первый экран с примером кабинета, «Как это работает», «Что внутри», призыв к регистрации; адаптив под телефон.

## Этап 0 — фундамент
- Репозиторий переведён с Android-проекта DarkPlayer на монорепозиторий ADMINO.
- API: FastAPI, настройки из окружения, единый формат ошибок, JSON-логи с request id, `/api/v1/health`.
- База: Alembic, первая миграция (расширения `btree_gist`, `citext`), тест наката и отката.
- Web: Next.js, токены дизайн-системы, шрифт Onest, временная стартовая страница.
- Docker-окружение, CI (линтеры, типы, тесты, сборка, поиск секретов), Dependabot.
