# Архитектура ADMINO

Полный согласованный документ (схема БД, маршруты, роли, дизайн-система, план этапов):
https://claude.ai/artifact/UjJ4JnCz2gnf1AQaoeAa38

## Кратко

- Модульный монолит: `apps/web` (интерфейс) и `apps/api` (все данные и правила).
- Одна PostgreSQL, `company_id` в каждой таблице компании, Row Level Security как второй рубеж.
- Каждый endpoint компании проходит цепочку: сессия → членство → статус компании → роль → тариф.
- Двойная запись невозможна: `EXCLUDE USING gist (staff_id, tstzrange)` + `Idempotency-Key`.
- Время хранится в UTC (`timestamptz`), у компании свой часовой пояс IANA.
