# 0001. Решения перед стартом (20.11.2026)

1. Хостинг — российский облачный провайдер (152-ФЗ): один VPS + S3-хранилище того же провайдера.
2. Роли: Manager — управление всем, кроме подписки; Admin — ресепшен (записи, клиенты, расписание).
3. SMS-подтверждение телефона клиента в MVP не делаем. Защита — ограничение частоты и ручное подтверждение.
4. Клиент может отменить запись по секретной ссылке не позднее чем за 24 часа (настройка компании).
5. Акцентный цвет и шрифт выбираются по 2–3 вариантам на макетах этапа 1.
